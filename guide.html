如何更新这个网站

1. 替换作品图片

所有图片放在 images/ 文件夹里。建议用纯英文命名，比如 project-01.jpg，避免中文和特殊符号。

替换时，每张卡片要改两个地方：

  • 卡片封面：<img src="images/project-01.jpg">
  • 详情页大图：data-cover="images/project-01.jpg"
两个路径要写成一样的，否则卡片显示一张图，点开详情却是另一张。

2. 修改作品文字

每张卡片上有标题、分类、年份、一句话描述。找到对应的 <a class="work-card">，改里面的文字和 data-* 属性：

data-title="项目名称"
data-category="分类"
data-year="2025"
data-desc="一句话描述"
data-body="<p>详情正文第一段</p><p>第二段</p>"

卡片上可见的文字（<h3> 和 <p>）也要同步改，不然列表和详情会对不上。

3. 添加一个新作品

复制一整张 <a class="work-card">...</a> 卡片，粘贴到作品网格里，然后：

  • 换图片路径
  • 改标题、分类、年份、描述
  • 改 data-* 属性
  • 保存刷新，网格会自动排版

4. 修改颜色

全站强调色（蓝色）定义在 :root 里的 --accent。改这一个值，标题、光标、悬停效果都会跟着变。

:root {
  --accent: #7692FF;
}

5. 更新线上版本

如果网站部署在 GitHub Pages：

  • 在本地改完文件
  • 提交并推送到 GitHub 仓库
  • 等一两分钟，线上自动更新
改完记得刷新浏览器（Ctrl + F5 或 Cmd + Shift + R）。
